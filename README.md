# LABVIEW Realistic Interactive Laboratory Game

## Run
Extract the ZIP and open `index.html` in a current browser. No server or installation is required.

## Corrected level mapping
1. Chemical Spill: spill image and identifier on the tipped bottle/spill.
2. Laboratory Fire: fire image and identifier on the flame.
3. Chemical Waste: waste image and identifier on the waste containers.
4. Hazard Labels: reagent image and identifier on the front pictogram.
5. Emergency Response: eyewash image and identifier on the eyewash station.

Correct answers receive 100 points. Incorrect answers receive 0 points. The final screen reviews every selected answer, the correct answer, and the explanation.
